# My Ludo - 2 Player Game

A 2-player Ludo game built with Python and Pygame!

## Installation

1. Clone the repository:
```bash
git clone https://github.com/sahuakash1222-stack/my-ludo.git
cd my-ludo
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## How to Play

1. Run the game:
```bash
python main.py
```

2. **Game Controls:**
   - Press **SPACE** to roll the dice
   - Click on a piece to move it (feature to be implemented)
   - Game alternates between 2 players

3. **Objective:**
   - Roll the dice and move all 4 pieces from home to the finish
   - First player to get all pieces home wins!

## Project Structure

- `main.py` - Game entry point and main loop
- `game.py` - Core game logic and game state management
- `board.py` - Board drawing and grid management
- `player.py` - Player and Piece classes
- `requirements.txt` - Python dependencies
